    Comment ça marche

    • Toucher la portée : pose une note à la hauteur touchée, dans la portée touchée (clé de sol ou de fa).
    • Maintenir puis glisser : la note suit le doigt, son nom s'affiche ; relâcher pour la poser.
    • Toucher une note existante : la sélectionne (orange). Durée, point, altération, ▲▼ s'appliquent à elle.
    • Clavier de piano : joue dans la portée active (bouton 𝄞/𝄢). Plusieurs doigts en même temps = accord.
    • Accord : quand il est activé, les notes suivantes s'empilent sur la note courante.
    • ▲ ▼ : monte/descend la note d'un degré ; appui long = une octave.
    • ◀ ▶ : déplacent le curseur pour insérer au milieu.
    • Les barres de mesure se placent toutes seules ; une note trop longue est coupée et liée.
    • Exporter (bouton orange) : un seul toucher par format (PDF, MusicXML, MIDI, PNG, SVG, ABC, LilyPond, projet) ou tout en .zip.
    • Tout est enregistré automatiquement sur le téléphone, même hors connexion.
